# UTS Pemrograman IV - Aplikasi Kontak (Flutter)

Fitur: Home + Daftar Kontak, tambah/ubah/hapus (dialog konfirmasi), Date Picker,
Color Picker, File Picker (pratinjau JPG/JPEG/PNG), validasi nama & telepon, SnackBar.

## Menjalankan
```
flutter create --platforms=android --project-name uts_pemrograman_iv .
flutter pub get
flutter run
```
